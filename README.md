# 🐾 PetFlow - Sistema de Filas para Pet Shops (Kanban)

O **PetFlow** é uma aplicação web de interface (Front-End) focada na organização ágil de filas de banho e tosa. Através de um quadro Kanban interativo, recepcionistas e tosadores conseguem gerenciar o fluxo de atendimento em tempo real, com monitoramento automatizado de tempo e alertas visuais.

## 🚀 Funcionalidades
* **Quadro Kanban Dinâmico:** Transição fluida entre as colunas "Em Espera", "Em Atendimento" e "Concluído".
* **Temporizador Assíncrono:** Alerta visual (vermelho pulsante) automático caso o pet ultrapasse o tempo limite configurado na coluna.
* **Design Responsivo (Mobile-First):** Layout adaptado perfeitamente para uso no smartphone via regras de *scroll-snap*.
* **100% Validado W3C:** Código HTML5 semântico e CSS3 sem erros ou avisos.
